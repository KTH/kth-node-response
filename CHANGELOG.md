# Changelog

All notable changes for major version updates will be documented here.

## 2.0.0

### Breaking changes

- Requires Node.js `>=24`.

### Notable changes

- Switched the test suite to Jest and added coverage for the response helpers
- Modernized the module export style by removing the IIFE wrapper
- Updated the tooling stack to ESLint 9, Husky 9, and lint-staged 17
- Refreshed dependencies and build configuration for the current Node 24 release line
